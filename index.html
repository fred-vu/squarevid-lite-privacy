SquareVid Lite Privacy Policy

Effective date: October 4, 2026

SquareVid Lite is a Chrome extension that lets you frame a video as a square and export an MP4. The extension processes the video you select on your device.

Information handled by the extension

When you choose a video, SquareVid Lite reads that file to preview, analyze, and export it. The extension also handles the file name, file type, file size, video properties needed for conversion, your crop and output settings, and export/download status. Some videos may contain personal information or other sensitive content; choose only files you intend to process.

Where information is stored and how it is used

The selected video and project details are stored locally in the extension's browser profile so you can continue editing after closing and reopening the editor. Temporary export data is stored in browser-local storage while the MP4 is prepared. Preferences and export status are saved using Chrome's local extension storage. The extension uses this information only to provide the video editing and export features you request.

When you save a finished video, SquareVid Lite asks Chrome to place it in your Downloads folder. That downloaded copy remains there until you delete it.

Sharing and remote services

SquareVid Lite does not upload your selected video, file name, project settings, or export data to the publisher or to an online video-processing service. The extension does not include advertising or analytics services and does not sell or share this information for advertising. The extension's processing code and media library are included in the extension package and run locally.

Chrome provides the local storage and download features used by the extension. When you save a video, Chrome handles the download as part of its browser functionality.

How long information is kept and how to delete it

The local working copy and project remain until you replace the video or use the extension's “Clear local project” action. Use that action to remove the current project and its temporary export data. Your Chrome preferences remain in local extension storage until you clear the extension's data or uninstall the extension. A video already saved to Downloads must be deleted from that folder separately.

Limited Use

SquareVid Lite's use of information is limited to providing its disclosed single purpose: locally framing and exporting videos selected by the user. The extension does not use this information for personalized advertising, and does not transfer it for unrelated purposes. This use complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Changes to this policy

If the extension's data practices change, this policy will be updated before the changed practices are introduced. The effective date above will show when this policy was last updated.
